Understanding Typography Conversions

In standard digital design and CSS specifications (W3C CSS Values Module), the reference pixel (px) is calibrated to 1/96th of an inch (96 DPI baseline).

Supported Typography Units (7 Units)

  • Pixel (px) (CSS digital display baseline (96 DPI)) — Primary SI / Base Reference Unit
  • Point (pt) (1/72 inch (Print, typography & iOS font size)) — 1 pt = 1.333333 px
  • Rem (rem) (Root em (16 px browser standard)) — 1 rem = 16 px
  • Em (em) (Relative font size (16 px standard)) — 1 em = 16 px
  • Pica (pc) (12 points / 16 px (Book & editorial typesetting)) — 1 pc = 16 px
  • CSS Inch (in (CSS)) (96 CSS pixels (CSS Print spec)) — 1 in (CSS) = 96 px
  • CSS Millimeter (mm (CSS)) (3.78 px (CSS Print spec)) — 1 mm (CSS) = 3.779528 px

Popular Typography Conversions

Pixel ⇄ Rem →
Divide pixels by 16 to get root rems (assuming default 16px browser base font size).
Rem ⇄ Pixel →
Multiply rem by 16 to get the computed pixel value (1.5 rem = 24 px).
Point ⇄ Pixel →
Multiply typography points by 4/3 (~1.333) to get CSS pixels (12 pt = 16 px).
Pixel ⇄ Point →
Multiply CSS pixels by 0.75 (3/4) to get typography points (16 px = 12 pt).
Pica ⇄ Pixel →
1 pica equals exactly 12 points or 16 CSS pixels.

Frequently Asked Questions

Common questions and verified calculations for typography units.

How do you convert pixels (px) to rem?

Divide the pixel value by 16 (assuming default root font size of 16px). For example, 16px = 1rem, 24px = 1.5rem, and 32px = 2rem.

What is the difference between rem and em in web development?

Both are relative units. A rem ("root em") is always relative to the root <html> element font size (typically 16px). An em is relative to the font size of its immediate parent element, which can compound in nested structures.

How do you convert print points (pt) to screen pixels (px)?

At the standard 96 DPI CSS baseline, 1 point (1/72 inch) equals 96/72 = 1.3333 pixels. Conversely, 1 pixel = 0.75 points (e.g. 16px = 12pt font size).
