Unit Definitions & Metrology Context

In standard digital design and CSS specifications (W3C CSS Values Module), the reference pixel (px) is calibrated to 1/96th of an inch (96 DPI baseline).

About Picas (pc): Pica (pc) is a unit in the Typography measurement category. It is widely used in 12 points / 16 px (book & editorial typesetting). Relative to the typography base unit, 1 pc equals 16 Pixels (px).

About CSS Millimeters (mm (CSS)): CSS Millimeter (mm (CSS)) is a unit in the Typography measurement category. It is widely used in 3.78 px (css print spec). Relative to the typography base unit, 1 mm (CSS) equals 3.779528 Pixels (px).
