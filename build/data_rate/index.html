Understanding Data Transfer Rate Conversions

Internet service providers advertise bandwidth in Megabits per second (Mbps). Real download speeds are displayed in Megabytes per second (MB/s). 8 Mbps = 1 MB/s.

Supported Data Transfer Rate Units (11 Units)

  • Bit per Second (bps) — Primary SI / Base Reference Unit
  • Kilobit per Second (Kbps) — 1 Kbps = 1000 bps
  • Megabit per Second (Mbps) — 1 Mbps = 1000000 bps
  • Gigabit per Second (Gbps) — 1 Gbps = 1000000000 bps
  • Terabit per Second (Tbps) (Fiber optic & datacenter backbones) — 1 Tbps = 1000000000000 bps
  • Byte per Second (B/s) (Bytes per second (File transfer rate)) — 1 B/s = 8 bps
  • Kilobyte per Second (KB/s) (Kilobytes per second) — 1 KB/s = 8000 bps
  • Megabyte per Second (MB/s) (Megabytes per second) — 1 MB/s = 8000000 bps
  • Mebibyte per Second (MiB/s) (File copy dialogs & torrent clients) — 1 MiB/s = 8388608 bps
  • Gigabyte per Second (GB/s) (Gigabytes per second) — 1 GB/s = 8000000000 bps
  • Terabyte per Second (TB/s) (GPU memory bandwidth (HBM3e)) — 1 TB/s = 8000000000000 bps

Frequently Asked Questions

Common questions and verified calculations for data transfer rate units.

Why is my download speed slower than my internet plan in Mbps?

Internet plans are sold in megabits (Mbps), while files download in megabytes (MB/s). Because 8 bits equal 1 byte, a 100 Mbps connection downloads at maximum ~12.5 MB/s.

How many Mbps is 1 Gbps?

1 Gigabit per second (Gbps) is equal to 1,000 Megabits per second (Mbps).
