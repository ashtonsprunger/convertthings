Understanding Digital Storage Conversions

1 Byte equals 8 bits. Decimal storage standards use powers of 1000 (1 GB = 1000 MB), while binary memory uses powers of 1024 (1 GiB = 1024 MiB).

Supported Digital Storage Units (15 Units)

  • Bit (b) — Primary SI / Base Reference Unit
  • Nibble (nibble) (4 bits / 0.5 byte (Hexadecimal digit)) — 1 nibble = 4 b
  • Byte (B) — 1 B = 8 b
  • Kilobyte (Decimal) (KB) — 1 KB = 8000 b
  • Kibibyte (Binary) (KiB) (Binary standard (Base-2 / 1024)) — 1 KiB = 8192 b
  • Megabyte (Decimal) (MB) — 1 MB = 8000000 b
  • Mebibyte (Binary) (MiB) (Binary standard (Base-2 / 1024)) — 1 MiB = 8388608 b
  • Gigabyte (Decimal) (GB) — 1 GB = 8000000000 b
  • Gibibyte (Binary) (GiB) (Binary standard (Base-2 / 1024)) — 1 GiB = 8589934592 b
  • Terabyte (Decimal) (TB) — 1 TB = 8000000000000 b
  • Tebibyte (Binary) (TiB) (Binary standard (Base-2 / 1024)) — 1 TiB = 8796093022208 b
  • Petabyte (Decimal) (PB) (Petabytes (1,000 TB)) — 1 PB = 8000000000000000 b
  • Pebibyte (Binary) (PiB) (1,024 TiB (Binary IEC standard)) — 1 PiB = 9007199254740992 b
  • Exabyte (Decimal) (EB) (1,000 PB (Cloud & data center scale)) — 1 EB = 8000000000000000000 b
  • Exbibyte (Binary) (EiB) (1,024 PiB (Binary IEC standard)) — 1 EiB = 9223372036854775808 b

Frequently Asked Questions

Common questions and verified calculations for digital storage units.

What is the difference between GB and GiB?

GB (Gigabyte) uses the decimal system (10⁹ = 1,000,000,000 bytes), commonly used by drive manufacturers. GiB (Gibibyte) uses binary (2³⁰ = 1,073,741,824 bytes), commonly used by operating systems.

How many megabytes are in a gigabyte?

In standard decimal storage, there are 1,000 megabytes in 1 gigabyte.
